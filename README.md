### Running a Solution Locally
If you want to test any solution file locally on your machine:
1. Clone this repository.
2. Compile the desired Java file:
   ```bash
   javac TopicName/Difficulty/FileName.java
   ```
3. Run the compiled class (make sure a `main` method is added for testing):
   ```bash
   java TopicName.Difficulty.FileName
   ```
